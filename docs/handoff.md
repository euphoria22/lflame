# Передача проекта: всё, что нужно новому чату

Этот файл — «память» проекта. Если чат с ассистентом потерян, в новом чате достаточно дать промпт
из раздела «Промпт для нового чата» — ассистент прочитает этот файл, `AGENTS.md` и `docs/*.md` и продолжит.
**Секретов (паролей, ключей, токенов) здесь нет и быть не должно** — только названия настроек и где они лежат.

## Промпт для нового чата

```
Ты продолжаешь работу над сайтом магазина LAFLAMME (репозиторий euphoria22/lflame).
Сначала прочитай docs/handoff.md, AGENTS.md и нужные файлы docs/*.md — там всё о проекте,
сервере, интеграциях, правилах и открытых задачах. Пиши код сам и пушь в main.
Я не разработчик, работаю на Windows: объясняй по-русски, простыми словами, давай готовые команды
для PowerShell/сервера по одной в блоке. Секреты в чат не присылаю — только через set-secret.sh.
```

## Кто и как

- Владелец — не разработчик, Windows, общаемся по-русски. Код пишет ассистент и сам пушит в `main`.
- Крупные изменения дизайна — сначала скриншоты/превью, публикация по слову «публикуй» (можно вести в отдельной ветке).
- Не любит «ИИ-шный» дизайн: строго, минимально, как на самом сайте.
- Коммиты на русском, в конце — строки соавторства (см. системные инструкции ассистента). Идентификаторы моделей в коммиты не писать.
- Правила кода и запреты — в `AGENTS.md` (не трогать node_modules и сборки, не править lockfile руками, не переписывать миграции, без точек с запятой, двойные кавычки, тексты интерфейса по-русски).

## Сайт и сервер

- Магазин: **https://laflamme.ru** (www → без www). Админка Medusa: **admin.laflamme.ru/app** — открыта с любого адреса; защита: двухфакторный вход (приложение-аутентификатор в профиле), лимит попыток, сообщение в Telegram о каждом входе. CMS: **cms.laflamme.ru** — только с IP из `ADMIN_ALLOW_IPS`.
- Сервер REG.RU `91.197.98.89`, вход: `ssh -p 2222 deploy@91.197.98.89`, проект в `~/lflame`.
- Обновить сайт: `cd ~/lflame && git pull && bash infra/scripts/deploy.sh`.
- Задать секрет/настройку: `bash infra/scripts/set-secret.sh ИМЯ [файл]` (по умолчанию `infra/.env.backend`, ввод скрыт). Общие настройки — `infra/.env` (домены, IP, БД).
- DNS — REG.RU (ns1/ns2.reg.ru), A `@` и `www` → сервер. Почта — Beget (admin@laflamme.ru), MX не трогали.
- Дамп БД перед переездом домена: `~/before-move.sql.gz`.
- Новый сотрудник в админку: пользователь — «Настройки → Пользователи → Пригласить» или `npx medusa user` в контейнере backend (ролей нет — доступ ко всему).

## Устройство

- `apps/backend` — Medusa v2 (каталог, заказы, оплаты, доставка, лояльность, админ-страницы и виджеты в `src/admin`).
- `apps/storefront` — Next.js 16 (cacheComponents, deploymentId; **partialPrefetching не включать** — ломает переходы, React #412).
- `apps/cms` — Payload CMS (баннер главной, блог, инфо-страницы, таблицы размеров).
- `infra` — docker compose, Caddy (HTTPS, CSP, IP-ограничения), скрипты деплоя/бэкапа, Cloudflare Worker для Telegram (`infra/telegram-relay/worker.js`).

## Подарочные карты: шоурум

Покупатель показывает QR из письма → продавец сканирует камерой телефона → на странице карты нажимает на код карты (строка LF-… на чёрной карте; скрытая ссылка, кнопки для покупателя нет) → открывается карта в админке → «Списать».
