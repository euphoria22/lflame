# Подписка на новости

Форма — в подвале сайта: «−10% на первый заказ за подписку».

## Как работает
- Покупатель вводит email → сразу приходит письмо с **одноразовым промокодом** вида `HELLO-7K3Q9P`.
  Код создаётся отдельно для каждого подписчика и срабатывает **один раз** — его нельзя «раздать» в чате скидок.
- Промокод вводится в корзине («Есть промокод?»). Со скидкой Laflamme Club не суммируется — сайт применит выгодную.
- Повторная подписка того же адреса нового кода не даёт.
- В каждом письме — ссылка «отписаться» (страница /unsubscribe). Письма о заказах после отписки приходят как обычно.

## Админка → «Рассылка»
- Включить/выключить форму, размер скидки (0 — подписка без промокода). Новый размер — для новых подписчиков.
- Список подписчиков: дата, промокод, использован ли, отписался ли.
- «Скачать CSV (Excel)» — для загрузки в сервис рассылок (Unisender, SendPulse, Mindbox и т. п.).

Сами рассылки (письма с новинками) пока делаются во внешнем сервисе по этому списку. Письма с промокодом отправляются
через почту сайта (SMTP) — пока она не настроена, письма только пишутся в журнал.

После обновления нужен `npx medusa db:migrate` в apps/backend (новая таблица подписчиков).
