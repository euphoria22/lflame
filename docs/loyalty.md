# Программа лояльности LAFLAMME

Админка → **«Лояльность»** (левое меню).

## Как считается
- Клиент = номер телефона. Уровень — по сумме покупок за последние 12 месяцев (настраивается): сайт + магазин.
- **Сайт:** заказ получен (отправка «Доставлена» — для СДЭК ставится сама) → запись «Ожидает» → через 7 дней «Засчитано». Отмена заказа отменяет запись.
- **Магазин и отгрузки из МоегоСклада:** розничные продажи, отгрузки, возвраты покупателей — раз в час (и кнопкой «Загрузить новые продажи из МС»).
  Учитываются документы на контрагента **с телефоном**. Обезличенные («Розничный покупатель», «Онлайн-заказ B2B», «Самовывоз», «опт») не участвуют — список в «Настройки».
  Отгрузки по заказам этого сайта пропускаются (они уже учтены как покупки на сайте).
- Каждую ночь: зачёт покупок, у которых прошло 7 дней, пересчёт уровней, письма о повышении и о скором понижении.

## Чтобы клиенты получали уровень
- **В магазине:** при продаже выбирайте контрагента (карточку покупателя) с телефоном, а не «Розничный покупатель». Иначе покупка не попадёт в программу.
- Один телефон — одна карточка. Дубли (один телефон в нескольких карточках) суммируются по телефону автоматически.

## Скидка на сайте
- Покупатель входит в кабинет, в профиле — его телефон. Телефон засчитывается, если он есть в заказах этого покупателя на сайте или в карточке МС с тем же email (пока нет входа по SMS).
- Скидка ставится в корзине сама: строка «Скидка LAFLAMME MEMBER −5%». Со скидкой на товар не суммируется — берётся большая из двух.
- Бренды без скидки уровня — в «Настройки».

## Что можно делать в админке
- Смотреть участников, искать по телефону / имени / email, фильтр по уровню (клик по плашке уровня).
- Карточка клиента: все покупки (сайт / магазин), что засчитано и что ожидает.
- **Корректировка суммы** (например, покупка не попала из МС) — с причиной, пишется в журнал.
- **Уровень вручную** (например, VIP для партнёра) — с причиной; снимается выбором «автоматически».
- Настройки: уровни (названия, пороги, скидки), период, задержки зачёта, исключения.
