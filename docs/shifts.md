# График смен

Раздел админки «Смены» (`apps/backend/src/admin/routes/shifts`): таблица по месяцам (работает / выходной / под вопросом),
сотрудники с ником в Telegram, рабочий чат и время напоминания.

- Данные — в metadata магазина: `shifts` (график и настройки), `shifts_bot` (служебное: offset, чаты, где есть бот, дата последнего напоминания).
- Задача `shifts-bot` (раз в минуту, `lib/shifts/bot.ts`): утреннее напоминание в рабочий чат (по Омску, один раз в день,
  не позже 3 часов после заданного времени) и приём команд через `getUpdates` (~48 секунд «длинного опроса» за запуск).
- Команды (только в рабочем чате и в чате уведомлений `TELEGRAM_CHAT_ID`): `/smena`, `/grafik`, `/grafik mesyac`, `/grafik next`, `/help`.
- Бот — тот же, что для уведомлений (`TELEGRAM_BOT_TOKEN`). Если используется посредник (`TELEGRAM_API_URL`),
  в коде Worker в Cloudflare должны быть разрешены методы `getUpdates` и `setMyCommands` (`infra/telegram-relay/worker.js`).
- В группе бот видит только команды (режим приватности) — этого достаточно. Если в чате несколько ботов, пишите `/smena@имя_бота`.
- Если у бота включён вебхук, `getUpdates` не работает — страница покажет ошибку.
