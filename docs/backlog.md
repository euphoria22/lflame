# Отложенные задачи

Обсуждены и согласованы «на потом». Перед началом — уточнить у владельца, актуально ли.

| Задача | Зачем | Оценка | Когда |
|---|---|---|---|
| Заголовок **Last-Modified** (товары — дата изменения товара, каталог — дата обновления цен/остатков) | Яндекс реже скачивает неизменившиеся страницы (аудит ITB, п. 17). Сейчас есть ETag, новые товары сообщаются через IndexNow | ~1 ч | в конце, после запуска |
| Климатические зоны в сортировке (юг / центр / Урал-Сибирь / север) по IP или городу доставки | сезонность точнее для регионов | 4–6 ч | когда в статистике видна география |
| Интерес на сайте (просмотры → корзины) в сортировке «Популярные» | сигнал до первых продаж | 1–2 ч | через 2–4 недели после запуска |
| Фильтр «Предзаказ» | отбор товаров в пути | ~1 ч | по запросу |
| Уведомления в Telegram через посредника (api.telegram.org с сервера в РФ недоступен; адрес — TELEGRAM_API_URL) | заказы в Telegram, а не только на почту | 1–2 ч + зарубежный сервер или Cloudflare | по запросу |
| Отзывы на товары со звёздами в поиске | коммерческий фактор Яндекса, кликабельность | 4–6 ч | по запросу |
| Фильтры «сезон», «материал», теги «демисезонные / кожаные» | аудит ITB, п. 24 | нужны новые поля в МоёмСкладе | после заполнения данных |

Решено **не делать**: телефон в шапке (ломает дизайн), страна и сертификаты на странице бренда.

Отложенные правки по аудиту (маска телефона, категории в подвале) — в `git stash` «Аудит itb…».
