# Посты во ВКонтакте

Раздел админки «Соцсети» → «ВКонтакте». Рекомендации общие с Telegram, но логика другая — **отложенные записи**:

- Посты заранее лежат в «Отложенных записях» сообщества на слоты расписания (по умолчанию 12:00–21:00 по Омску раз в 2 часа) на 7 дней вперёд (настраивается, 1–14). Их видно и можно поправить прямо во ВКонтакте.
- Раз в 10 минут (задача `vk-plan`): вышедшие записи — в историю товара; удалённые вручную во ВКонтакте — забываются; свободные слоты заполняются сначала очередью («В очередь»), потом рекомендациями (если включено).
- До выхода: товар закончился или снят с сайта — запись удаляется, слот займёт другой товар; изменилась цена, размеры или акция — текст отложенной записи обновляется.
- **Вышедшие посты сайт не меняет** (алгоритмы ленты не любят правки).
- «Убрать» в админке удаляет отложенную запись; убранный товар не предлагается 14 дней.
- «Сейчас» в карточке товара — пост сразу, вне расписания.
- Фото в посте (Telegram и ВКонтакте): в карточке товара, блок «Соцсети» → «Фото в посте» — выбрать нужные по порядку (до 10, `metadata.social_photos`). Не выбрано — все фото подряд, как на сайте. Уже стоящие в отложке ВКонтакте записи остаются со старыми фото (их можно «Убрать» — слот займёт товар заново).
- Текст поста — без разметки (ВКонтакте не поддерживает жирный), зачёркнутая старая цена — символами.

## Подключение (VK ID)

Новые приложения ВКонтакте (id.vk.com) не выдают бессрочный ключ по старой ссылке oauth.vk.com («Security Error»). Поэтому:

1. Приложение на id.vk.com (только платформа Web): базовый домен `laflamme.ru`, доверенный Redirect URL — `https://admin.laflamme.ru/admin/vk/callback`. В «Доступах» приложения — стена, фотографии, сообщества (если есть такой раздел).
2. Админка → «Соцсети» → «ВКонтакте» → «Подключение»: ID приложения (54898100), сообщество (`laflammeru`) → «Подключить ВКонтакте» → разрешить (войти владельцем сообщества).
3. Сайт получает ключ (живёт час) и продлевает его сам (refresh token, VK ID OAuth 2.1 + PKCE). Хранится в `metadata.vk_auth` магазина. Отключить — кнопкой «Отключить» или в настройках ВКонтакте (Приложения).

Старый способ тоже поддерживается: `VK_ACCESS_TOKEN` и `VK_GROUP_ID` в `infra/.env.backend` (если ключ задан там, он главнее подключения из админки).

## Код

`apps/backend/src/lib/vk/client.ts` (API, VK ID: подключение и продление ключа, загрузка фото), `api/admin/vk/*` (подключение), `lib/vk/post.ts` (текст поста), отложка — `lib/vk/plan.ts`, общая логика очередей — `lib/telegram/channel.ts` (`Net = "tg" | "vk"`). История постов товара — `metadata.vk`, очередь и отложенные записи — `metadata.vk_queue` магазина.
