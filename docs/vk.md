# Посты во ВКонтакте

Раздел админки «Соцсети» → «ВКонтакте». Рекомендации общие с Telegram, но логика другая — **отложенные записи**:

- Посты заранее лежат в «Отложенных записях» сообщества на слоты расписания (по умолчанию 12:00–21:00 по Омску раз в 2 часа) на 7 дней вперёд (настраивается, 1–14). Их видно и можно поправить прямо во ВКонтакте.
- Раз в 10 минут (задача `vk-plan`): вышедшие записи — в историю товара; удалённые вручную во ВКонтакте — забываются; свободные слоты заполняются сначала очередью («В очередь»), потом рекомендациями (если включено).
- До выхода: товар закончился или снят с сайта — запись удаляется, слот займёт другой товар; изменилась цена, размеры или акция — текст отложенной записи обновляется.
- **Вышедшие посты сайт не меняет** (алгоритмы ленты не любят правки).
- «Убрать» в админке удаляет отложенную запись; убранный товар не предлагается 14 дней.
- «Сейчас» в карточке товара — пост сразу, вне расписания.
- Текст поста — без разметки (ВКонтакте не поддерживает жирный), зачёркнутая старая цена — символами.

## Что нужно на сервере

- `VK_GROUP_ID` — номер сообщества или его короткое имя (`laflammeru`): номер сайт узнает сам.
- `VK_ACCESS_TOKEN` — ключ доступа владельца или администратора сообщества с правами `wall, photos, groups, offline`. Ключ самого сообщества не подходит: им нельзя загружать фото на стену.

Сохранить (ввод скрыт):

```
bash infra/scripts/set-secret.sh VK_GROUP_ID
bash infra/scripts/set-secret.sh VK_ACCESS_TOKEN
bash infra/scripts/deploy.sh
```

## Как получить ключ доступа

1. Создать приложение ВКонтакте типа Standalone (vk.com/apps?act=manage → «Создать», или в кабинете разработчика ВКонтакте), запомнить его ID.
2. Открыть в браузере, подставив ID приложения:
   `https://oauth.vk.com/authorize?client_id=ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,photos,groups,offline&response_type=token&v=5.199`
3. Разрешить доступ. В адресной строке открывшейся страницы — `access_token=...&expires_in=0`: значение между `access_token=` и `&` и есть ключ. `expires_in=0` — ключ бессрочный.

ВКонтакте меняет порядок выдачи ключей (VK ID). Если этот способ не сработает — ключ можно получить через VK ID-приложение; код от этого не меняется, нужен только сам ключ с теми же правами.

## Код

`apps/backend/src/lib/vk/client.ts` (API, загрузка фото), `lib/vk/post.ts` (текст поста), отложка — `lib/vk/plan.ts`, общая логика очередей — `lib/telegram/channel.ts` (`Net = "tg" | "vk"`). История постов товара — `metadata.vk`, очередь и отложенные записи — `metadata.vk_queue` магазина.
