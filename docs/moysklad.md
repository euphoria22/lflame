# МойСклад и сайт: как это работает

Инструкция для сотрудников LAFLAMME. Технические требования — в [ТЗ, раздел 3](TZ.md#3-интеграция-с-моимскладом).

## Коротко

- **МойСклад — главный.** Названия, цены, размеры и остатки берутся оттуда. На сайте их не правят: при следующей синхронизации они перезапишутся.
- **На сайте правят:** фото, описания, SEO-поля, адрес страницы (slug), бренды (описание, логотип).
- **Синхронизация:** изменения из МоегоСклада попадают на сайт в течение нескольких минут, остатки — каждые 10 минут.
- **Где смотреть:** админка магазина → раздел **«МойСклад»**: журнал синхронизаций, кнопки ручного запуска, список товаров с проблемами.

## Правила ведения товаров

1. **Один товар = одна модель одного цвета.** Размеры — модификации (характеристика «Размер»).
2. **Название:** `Тип Бренд Модель Цвет`, например «Худи Calvin Klein Monogram Logo Fleece Black». Из названия сайт сам определяет бренд и цвет.
3. **Цены:** «Цена продажи» — цена на сайте. «Старая цена» — зачёркнутая цена, если она больше цены продажи.
4. **Остатки:** на сайт идёт свободный остаток (остаток минус резерв) со склада **«Основной склад (Партизанская 5а/8)»**.
5. **Доп. поля** (заполнять желательно, но не обязательно):
   - **Бренд** — если заполнено, важнее, чем бренд из названия;
   - **Для кого** — Мужское / Женское / Унисекс. Если пусто, товар считается мужским (кроме названий со словом «Женские»);
   - **Цвет** — если заполнено, важнее, чем цвет из названия;
   - **Длина, Ширина, Высота** и **вес** — нужны для точного расчёта доставки.
6. **Группа товара** = категория на сайте. Группа «Товары интернет-магазинов» не используется.

## Когда товар появляется на сайте

| Ситуация | Что на сайте |
|---|---|
| Новый товар с ценой и остатком на «Основном складе» | появляется автоматически |
| Товар без остатка, которого ещё не было на сайте | не появляется |
| Товар закончился | остаётся на сайте с пометкой «Нет в наличии» |
| Товар снова пришёл | снова доступен для заказа |
| Товар перенесён в архив МоегоСклада | снимается с публикации |
| У товара нет фото | создаётся, но не публикуется, пока не добавят фото |

## Отчёт «Товары с проблемами»

В разделе «МойСклад» админки. Что означает каждая проблема и как её исправить:

| Проблема | Что сделать в МоемСкладе |
|---|---|
| Бренд не определён | заполнить доп. поле «Бренд» или добавить написание бренда в справочник брендов на сайте |
| Цвет не определён | заполнить доп. поле «Цвет» |
| Нет категории | положить товар в группу (не «Товары интернет-магазинов») |
| Нет цены продажи | заполнить «Цена продажи» |
| Повтор размера | у двух модификаций одинаковый размер (например, латинская M и русская М) — исправить |
| Нет фото, не опубликовано | добавить фото в МоемСкладе или на сайте |

Ссылка в отчёте открывает товар в МоемСкладе.

## Права технического пользователя

Сайт подключается к МоемуСкладу под отдельным сотрудником с минимальными правами:

| Раздел | Права |
|---|---|
| Моя компания | Юр. лица — смотреть |
| Продажи | Заказы покупателей — смотреть, создавать, редактировать, проводить; Отгрузки и Возвраты покупателей — только смотреть |
| Товары | Товары и услуги — только смотреть |
| CRM | Контрагенты — смотреть, создавать, редактировать |
| Склад | Остатки и склады — смотреть |
| Деньги | Входящие платежи — смотреть, создавать, редактировать |
| Розница | Розничные продажи и возвраты — смотреть |
| Настройки | Веб-хуки — разрешить |
| Остальное | нет доступа |

Токен этого пользователя хранится только в настройках сервера (переменная `MOYSKLAD_TOKEN`) и никогда не пересылается в чатах и письмах.

## Для разработчика

- Код: `apps/backend/src/lib/moysklad/` (синхронизация), `apps/backend/src/modules/moysklad/` (клиент API, журнал), `apps/backend/src/lib/catalog/` (бренды, цвета, размеры, транслит).
- Ручной запуск:

  ```bash
  cd apps/backend
  npx medusa exec ./src/scripts/moysklad-sync.ts          # изменения с прошлого раза
  npx medusa exec ./src/scripts/moysklad-sync.ts full     # весь каталог
  npx medusa exec ./src/scripts/moysklad-sync.ts stock    # только остатки
  ```

- Расписание включается переменной `MOYSKLAD_SCHEDULE_ENABLED=true`.
- Вебхуки (на production, нужен публичный адрес бэкенда):

  ```bash
  npx medusa exec ./src/scripts/moysklad-webhooks.ts https://api.example.ru
  ```

- Фото товаров МойСклад отдаёт через хранилище Selectel (`s3.ru-6.storage.selcloud.ru`): если сервер ограничивает исходящий трафик, этот адрес должен быть разрешён.

## Предзаказ
- На сайте: админка → товар → блок «Продажа на сайте» → «Предзаказ». Все размеры можно заказать без остатка, на сайте — пометка «Предзаказ» и кнопка «Оформить предзаказ». В заказе (Telegram, письмо, комментарий в МС) позиция помечена «ПРЕДЗАКАЗ».
- Товара, которого ещё нет на остатке, на сайте нет (создаются только товары в наличии). Чтобы он появился заранее: в МоёмСкладе создайте у товаров доп. поле-флажок **«Предзаказ»** и отметьте его — при синхронизации товар появится на сайте уже с пометкой «Предзаказ». Дальше флажок ведётся в админке сайта.

## Без скидки программы лояльности
Админка → товар → «Продажа на сайте» → «Не действуют скидки LAFLAMME». Для целых брендов — «Лояльность» → «Настройки» → «Бренды без скидки уровня».
