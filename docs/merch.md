# Мерчендайзинг

Раздел админки «Мерчендайзинг» (`apps/backend/src/admin/routes/merch`). Сейчас — основа: план зала и оборудование.

- Варианты расстановки — модуль `merch` (таблица `merch_layout`: название, `data` JSON, `is_current`). API: `/admin/merch/layouts`, `/admin/merch/layouts/:id`.
- Содержимое варианта (`apps/backend/src/admin/lib/merch/catalog.ts`): зал (размеры, высота в коньке и у стен — мансарда, отделка стен, двери/окна), оборудование (тип, центр x/y в метрах от левой и верхней стены, поворот, размеры, высота крепления), зоны (сила места 1–5), подложка-картинка.
- Каталог оборудования собран по фото магазина: пристенные системы, стойки на плите, стойки из труб, круглые стойки, стеллажи из труб, металлические шкафы, П-образные полки 60 и 40 см, сетка, столы, пуфы, манекен, примерочные, касса, колонны, перегородка, треки света. Всё — нержавейка.
- План (`plan.tsx`, SVG): перетаскивание, прилипание к стенам, шаг 5 см, зоны с изменением размера. 3D (`scene.ts`, three.js): «кукольный домик» с прячущимися стенами, обход зала от входа, перетаскивание в 3D, снимок PNG. Вещи на вешалах — пример (случайные цвета), не реальные товары.
- Первый вход создаёт черновик по присланному плану; размеры примерные до замеров.
- Дальше: раскладка товаров по оборудованию по данным умной сортировки, задания консультантам с фото-отчётом, смена сезона. Склад общий с интернет-магазином — «в зале» будет отметкой в задании.
