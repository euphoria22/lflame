## LAFLAMME CMS rules

- Payload CMS 3 for site content only (banners, home blocks, pages, journal). Products and orders live in Medusa.
- Admin at `/cms`, REST API at `/api`. Files in `src/app/(payload)/` are generated by Payload: do not edit them; regenerate the import map with `npx payload generate:importmap`.
- Do NOT enable `cacheComponents` in this app: the Payload admin does not support it.
- Admin UI language is Russian (`i18n` in `payload.config.ts`); give collections and fields Russian `labels`.
- Code style: no semicolons, double quotes, 2-space indent.
